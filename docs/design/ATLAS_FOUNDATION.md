# Zoufeng Atlas — Design Foundation

**Status:** Design prototype. **Not approved for full development.**  
**Approval line required:** `DESIGN APPROVED — BEGIN IMPLEMENTATION`

## What this is

A high-fidelity, clickable visual language for the complete Zoufeng B2C mobility and travel operating system. Existing catalog, pricing, and booking objects were reused as **content**. The previous neon / glass HUD was retired.

## Visual name

**Atlas** — editorial travel paper + runway command strips.

- Passenger: limestone canvas, photographic corridors, copper wayfinding, serif display
- Driver: dusk field, one primary action, paper job tickets
- Operations: dark cartographic room + inspector
- Admin / finance: light ledger density

## Delivered

- Design tokens and component primitives
- Four distinct shells
- 47 representative routes (see `/design`)
- Service-specific booking (airport, drop, P2P, hourly, rental, instant)
- Working preview using existing in-browser store

## Stop line

Do not expand into production APIs, payments, or data migrations until the human owner approves the visual direction.
